How the draw keeps it fair

Add at least three names. One draw holds up to 30. Pick a budget before you draw. Then send each link yourself. The draw runs in your browser.

The honest part. The organizer holds every link. The organizer could open one. Links are hidden, not locked. The seal is trust, not a lock. Send each link to its person only.

Is a name draw the same game?

Yes. A gift exchange is Secret Santa. One name drawn in secret. One gift bought for that person.

What if no fair draw exists?

The draw says so first. No links get made. Loosen one marked pair. Then draw again right away.
