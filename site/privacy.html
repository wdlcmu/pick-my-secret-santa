Privacy

The short version: The draw is made in your browser, and new draws also make short links. For a short link, our server stores your name and your match under a random code, in a form we can read; the address itself holds nothing readable, but we run this server, so we can read what is stored. Anyone with a link can open that link's match, and the organizer's group link can reach every person's link, so it can reach every match. Cloudflare Web Analytics counts visits here, and PostHog counts draws, shares, and link opens, as counts only. A draw notes which of its links were opened, by random code only. There are no accounts here.

What the draw does

You type in the names, a budget, and any pairs who should not draw each other, and the draw math runs in your browser. To make the short links, our server stores each name and match in a form we can read.

You can also say what a person is into, in your own words. In the draw tool, those words are matched on this device; they are not sent or saved, and no name is asked for there. If you use the Ask panel instead, your words go to this site's AI, which reads them and picks from the site's gift list, and nothing you type in the Ask panel is saved.

After a draw, your browser saves your links on this device only, so you can send a link again later. You can clear them any time with two taps. On a shared device, clear them when you are done.

Private links

Each link shows one person's match, and no one else's. With a long link, the match sits inside the link itself, in coded words after the # mark. That part is not sent to our server when the link opens, but anyone who holds the link can read it.

New draws also make a short link for each person. A short link's address holds only a random code, and nothing in it can be read. Your name and the name you drew sit on our server under that code, in a form we can read; we run this server, so we can read the names and matches stored for short links. That record also holds the group's names, so whoever opens the link can start their own draw with the same crew.

A link is hidden from plain sight, not locked: anyone with a link can open it, so send each link only to its person. If a short link leaks, the organizer can kill that one person's link without a redraw. Each short link deletes itself after about 13 months.

The organizer also gets one group link, for a manage page. Its record holds the group name, the budget, each person's name and short code, and any keep-apart pairs the organizer set, but no match of its own. Even so, each short code opens that person's link, so the group link can reach every match in the group. Treat it like a key to the whole draw. It deletes itself after about 13 months too.

One exception: a person running a draw they are not part of can open a list of the pairings from the manage page, after a warning screen and a confirmation that they are not in the draw. That confirmation is trust, not a lock: the page takes their word for it, and the list is meant to stay closed to every player, including an organizer who is playing.

You can also print the draw as folded paper slips, one per person, from the results screen or the manage page. The slips are made in the organizer's browser, from the draw that is already there; printing sends us nothing and stores nothing new. A slip shows its match to anyone who unfolds it, and a printed slip cannot be killed or replaced the way a link can, so hand each slip only to the person named on it.

The organizer can also create one link for the whole group, under its own separate code. It opens a page listing the group's names: each person taps their own name, confirms it is them, and sees only their own match. Anyone holding the link can see the names and can open a match by picking a name, so it is for groups that trust each other. The page marks each name once it has been opened, and opening a name again asks for the same confirmation. That link cannot open the manage page or the pairings list, and its record holds no names or matches of its own, only a note of which names have been opened through it.

When a link opens, it leaves a note behind: a random code for that draw, plus the word opened or saw, and no name, no match, and no gift pick. The organizer's list reads those notes to see who still needs a nudge, and each note deletes itself after 120 days. You share links with your own apps, and sharing starts only when you tap a button.

Starting your own draw

After you see your match, the page offers a link to start your own draw. If you tap it, the names from the draw you were in are kept on this device for up to a week, so your new draw can open with those names already filled in. Nothing is kept for that unless you tap the link, and you can change or clear every filled-in name before you draw.

The Start your own draw link also carries your own private link's code, so another browser or another device can fill in the same names. Anyone with that link can open your match and see the group's names, so treat that link like your private link.

How visits are counted

This site loads Cloudflare Web Analytics, which sends page and performance counts to Cloudflare; Cloudflare says its beacon uses no cookies. The site also loads PostHog, which counts page views, draws, shares, link opens, card saves, pairings-list views, group page views and name picks, and print previews and print taps for paper slips. It also counts return visits and Start your own draw taps.

Gift idea matches are counted as a count of picks only. PostHog counts actions only, never what you type. On a first visit it also remembers which site or app sent the visit: only that name, never the full link that was tapped. No names, matches, gift picks, or link parts are sent, and PostHog sets no cookie on this site.

Your browser also keeps one yes-or-no mark on this device. It says this browser has drawn or peeked before; it holds no names, matches, gift picks, or links, and it is what lets a later visit count as a return visit.

Your saved draw stays on this device too. It holds your names and each person's link, and it marks which links you have shared from this device. On a new draw it also holds the random codes the open-notes use, each person's short-link code, and your group link's code. It is never sent to us or to PostHog, and the counts never include anything inside it.

The ChatGPT plugin

The Pick My Secret Santa plugin for ChatGPT is published and live. Here is how it works. In the chat, you set the group up in words; the chat does the talking, and the draw still runs here, on this site. The plugin never draws and never assigns anyone.

If you give the chat your group's names, they pass through our server once. They are held in memory only, to build your pre-filled link, and they are never stored. Our server counts plugin tool calls by day, as counts only. The names also stay in your chat history, and that history is kept under ChatGPT's rules, not ours.

O que o sorteio faz

Você digita os nomes, um orçamento e os pares que não devem se tirar, e as contas do sorteio rodam no seu navegador. Para criar os links curtos, nosso servidor guarda cada nome e combinação de um jeito que a gente consegue ler.

Você também pode dizer do que uma pessoa gosta, com as suas próprias palavras. Na ferramenta do sorteio, essas palavras são comparadas neste aparelho; elas não são enviadas nem guardadas, e nenhum nome é pedido ali. Links privados

Cada link mostra a combinação de uma só pessoa, e de mais ninguém. Com um link longo, a combinação fica dentro do próprio link, em palavras codificadas depois do símbolo #. Essa parte não é enviada ao nosso servidor quando o link abre, mas quem tiver o link consegue lê-la.

Os sorteios novos também criam um link curto para cada pessoa. O endereço de um link curto guarda só um código aleatório, e nada nele dá para ler. Seu nome e o nome que você tirou ficam no nosso servidor sob esse código, de um jeito que a gente consegue ler; a gente opera este servidor, então a gente consegue ler os nomes e as combinações guardados para os links curtos. Esse registro também guarda os nomes do grupo, para quem abrir o link poder fazer o próprio sorteio com o mesmo grupo.

Um link fica escondido da vista, não trancado: quem tiver um link pode abri-lo, então envie cada link só para a sua pessoa. Se um link curto vazar, o organizador pode desativar o link daquela pessoa sem refazer o sorteio. Cada link curto se apaga sozinho depois de cerca de 13 meses.

O organizador também recebe um link de grupo, para uma página de gerenciamento. O registro dele guarda o nome do grupo, o orçamento, o nome e o código curto de cada pessoa, e os pares que o organizador marcou para ficarem separados, mas nenhuma combinação própria. Mesmo assim, cada código curto abre o link daquela pessoa, então o link de grupo pode chegar a cada combinação do grupo. Trate-o como uma chave do sorteio inteiro. Você também pode imprimir o sorteio como bilhetes de papel dobrados, um por pessoa, da tela de resultados ou da página de gerenciamento. Um bilhete mostra a combinação dele para quem o desdobrar, e um bilhete impresso não pode ser desativado nem substituído como um link, então entregue cada bilhete só para a pessoa nomeada nele.

Quem organiza também pode criar um link único para o grupo inteiro, com seu próprio código separado. A lista do organizador lê essas anotações para ver quem ainda precisa de um lembrete, e cada anotação se apaga sozinha depois de 120 dias. Você compartilha os links com os seus próprios aplicativos, e o compartilhamento só começa quando você toca em um botão.
