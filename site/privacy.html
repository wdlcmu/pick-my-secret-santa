Pick My Secret Santa

Privacy

The short version: Names and the draw stay in your browser. Cloudflare Web Analytics counts visits here. PostHog counts draws, shares, and link opens, as counts only. A draw notes which of its links were opened, by random code only. There are no accounts here.

What the draw does

You type names, a budget, and any pairs who should not draw each other.

The draw math runs in your browser.

Nothing you type on this site is sent to us.

Say what a person is into, in your words.

In the draw tool, those words are matched on this device, and they are not sent or saved.

No name is asked for there.

If you use the Ask panel instead, your words go to this site's AI, which reads them and picks from the site's gift list.

Nothing you type in the Ask panel is saved.

After a draw, your browser saves your links.

They stay on this device only.

That way you can send a link again later.

You can clear them any time with two taps.

On a shared device, clear them when done.

Private links

Each link holds one person's match.

The match sits inside the link itself.

Our server never sees the match.

A link is hidden from plain sight, not locked.

Anyone with a link can open it.

Send each link only to its person.

When a link opens, it notes that it opened.

The note holds a random code made for that draw, plus the word opened or saw.

It holds no name, no match, and no gift pick.

The organizer's list reads the notes.

That is how they can see who still needs a nudge.

Each note deletes itself after 120 days.

You share links with your own apps.

Sharing starts only when you tap a button.

How visits are counted

This site loads Cloudflare Web Analytics.

It sends page and performance counts to Cloudflare.

Cloudflare says its beacon uses no cookies.

This site also loads PostHog.

PostHog counts page views, draws, shares, link opens, and card saves.

Gift idea matches count as a count of picks only.

It also counts return visits.

Start your own draw taps count too.

It counts actions only, never what you type.

No names, matches, gift picks, or link parts are sent.

PostHog sets no cookie on this site.

Your browser keeps one yes-or-no mark on this device.

It says this browser has drawn or peeked before.

It holds no names, matches, gift picks, or links.

It lets a later visit count as a return visit.

Your saved draw stays on this device too.

It holds your names and each person's link.

It also marks which links you have shared from this device.

On a new draw it also holds the random codes the open-notes use.

It is never sent to us or to PostHog.

Counts never include anything inside it.

The ChatGPT plugin

Pick My Secret Santa also runs as a plugin inside ChatGPT.

In the chat, you set the group up in words.

The chat does the talking. The draw still runs here, in your browser.

The plugin never draws and never assigns anyone.

If you give the chat your group's names, they pass through our server once.

They are held in memory only, to build your pre-filled link.

They are never stored.

Our server counts plugin tool calls by day, as counts only.

The names also stay in your chat history.

That history is kept under ChatGPT's rules, not ours.

Children

Adults run the draws on this site.

Some gifts here are for children.

It is not directed at children under 13.
