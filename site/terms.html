Pick My Secret Santa

Terms

These terms cover this website and its ChatGPT plugin.

This site is a free Secret Santa tool.

You add names and a budget.

It draws matches and suggests gifts.

There are no ads on this site.

There are no accounts or sign-ups.

The site sells nothing at all.

How the draw works

The draw is random, with two rules.

Nobody draws their own name.

Pairs you mark never draw each other.

The draw runs in your browser.

Our server stores each name and match for the short links, in a form we can read.

Some rule sets cannot form a draw.

The site will say so when that happens.

The ChatGPT plugin

The plugin sets a group up inside ChatGPT.

It hands back one pre-filled link to this site.

It never draws or assigns anyone.

The draw happens here, in your browser.

Names given in chat pass through our server in memory only.

They build the link and are never stored.

What you type in chat also sits in your chat history.

That history is kept under ChatGPT's rules.

Where gift ideas come from

Gift ideas come from a fixed list.

The list is Santa's 212, from the shared 255-idea bank it shares with The Present Picker.

Your budget is a hard filter.

A gift hint raises matching ideas.

Budget bands are guides, not exact prices.

Stores set real prices, and prices change.

Buying your gift

This site links to no stores.

It takes no payment from you.

It places no orders for you.

You choose where and what to buy.

Check each idea before you buy.

Accounts and data

PostHog counts draws, shares, and link opens.

It also counts return visits. All as counts only.
