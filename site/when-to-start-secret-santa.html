When should you start Secret Santa?

Start when your group can agree two things: one budget and one gift day. The draw itself takes about 2 minutes, any day you run it. The buying needs the lead time — this site's rule is a buy-by date a week before gift day.

The order that works, from the site's own run list

Pick the gift exchange day. Agree one gift budget — most groups land between $10 and $30. Collect every name, and what each person likes. Run the draw and send each private link to its person only. Set the buy-by date a week before the exchange, so nobody is shopping on the day.

Gifts going by mail? Start earlier

Mail each gift in a plain box, early. Holiday mail runs slow. Agree the mail-by day before anyone buys — the day is the group's to set, and this site holds no date for you.
