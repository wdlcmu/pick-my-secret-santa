Pick My Secret Santa

Works with your AI

Pick My Secret Santa runs an MCP server that your AI assistant can call, to run a draw or to find the gift. Not a developer? You do not need any of this: the draw runs right on the homepage.

What your AI can do

Run the draw in chat. Give your AI the names (3 to 100 people), and it runs the draw and hands back a private link for each person. It returns the links only, never who drew whom.

Pick the gift. Gift ideas from Santa's 212 hand-checked picks, matched to your person and your budget.

Check a setup first. Your AI can check a group before anyone draws (names, budget, pairs to keep apart) and hand you a pre-filled link to finish the draw on this site.

Answer rule questions. How Secret Santa works, and how the secrecy holds.

How names and matches are handled

The draw is picked in your browser. To make the private links work, the names and matches are stored on our server, in a form we can read.

The same is true when your AI runs the draw in chat: the names and matches are stored on our server, in a form we can read, so each private link can open.

Connect it

1. Copy the server address

https://mcp.pickmysecretsanta.com/mcp

2. Add it to your AI

Claude Code: one command 
claude mcp add --transport http secret-santa https://mcp.pickmysecretsanta.com/mcp
Claude Desktop or Cursor: paste into the MCP settings 
{
  "mcpServers": {
    "secret-santa": {
      "url": "https://mcp.pickmysecretsanta.com/mcp"
    }
  }
}

Any other assistant that takes an MCP server address can use it the same way.
