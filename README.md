# Pick My Secret Santa

A private Secret Santa draw that runs entirely in your browser. No accounts, no server, nothing stored or sent. The organizer makes the draw, sends each person their own private link, and each link reveals one match plus a gift pick.

Live at https://pickmysecretsanta.com

The deployable site lives in `site/` (the Pages project's build output directory). Build notes and the launch packet are in `PACKET.md`; QA evidence is in `qa/`.

Built with Muse.
