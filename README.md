# Pick My Secret Santa

A private Secret Santa draw, picked in your browser. To make the private links work, the names and matches are stored on our server, in a form we can read. No accounts, no email, no ads. The organizer makes the draw, sends each person their own private link, and each link reveals one match plus a gift pick.

Live at https://pickmysecretsanta.com

The deployable site lives in `site/` (the Pages project's build output directory). Build notes and the launch packet are in `PACKET.md`; QA evidence is in `qa/`.

Built with Muse.
